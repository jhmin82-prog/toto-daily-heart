# 🐾 토토의 매일하트

아이의 하루 학습(영어·수학·국어)과 독서량을 하트로 채워 기록하는 웹 앱입니다.
설치 없이 브라우저에서 바로 열 수 있고, 모든 기록은 그 기기의 브라우저(localStorage)에만 저장됩니다.

## 쓰는 법

1. 아래 주소를 휴대폰이나 태블릿 브라우저로 엽니다.
   - https://jhmin82-prog.github.io/toto-daily-heart/
2. **📅 달력** — 날짜별로 하트를 몇 개 채웠는지 한눈에 봅니다.
3. **🚂 오늘 체크** — 영어(바깥 하트)·수학(가운데 하트)·국어(안쪽 하트)를 하나씩 채우면 오늘 하트 9개가 모이고 ⭐가 완성됩니다.
4. **📚 독서량** — 읽은 책을 기록하면 일별·주별·월별·연별로 쌓인 양을 볼 수 있습니다.

## 참고

- 서버도 계정도 필요 없습니다. `index.html` 한 파일이 전부입니다.
- 기록은 브라우저마다 따로 저장되므로, 기기를 바꾸거나 브라우저 데이터를 지우면 새로 시작합니다.
- 홈 화면에 추가하면 앱처럼 전체 화면으로 열립니다.
